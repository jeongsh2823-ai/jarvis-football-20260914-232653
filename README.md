# Jarvis Football

한국시간 기반 5개 팀 축구 모바일웹. GitHub Pages에서 동작하는 독립 프로젝트입니다.

## 사용

- 상단: 메인 / 맨유 / 토트넘 / 아틀레티코 마드리드 / 레알 마드리드 / 인천 유나이티드
- 팀별: 일정 / 순위 / 뉴스. 최근 결과를 누르면 득점 상세가 열립니다.
- 모바일 360–430px, 데스크톱 대응. PWA 설치 불필요.

## 실행

Node.js 22 이상. 외부 패키지 설치 없이 실행합니다.

```sh
npm run collect
npm test
npm start
```

## 데이터와 갱신

- FotMob: 전체 대회 일정, 결과, 득점·PK·자책골·도움, 현재 리그 순위.
- ESPN: 유럽 4개 팀 전체 대회 일정/결과/득점/순위 대체 소스.
- 365Scores: 인천 일정/결과/득점/순위 대체 소스. 현재 소속 리그는 제공 데이터에서 찾습니다.
- Google News RSS: 한국어 팀 뉴스, 제목·출처·게시시각·링크만 수집. 기사 본문은 저장하지 않습니다. 원문으로 연결되는 Google News 링크입니다.
- 양쪽 소스의 홈/원정 팀명과 날짜를 대조합니다. 미확정 시간이 다른 소스에서 확인되면 확인된 시간을 사용합니다. 확정 시간끼리 다르면 충돌을 표시하며 임의 합성하지 않습니다.
- 시간은 UTC 또는 UTC 오프셋을 포함해 보관하고 `Intl.DateTimeFormat`의 `Asia/Seoul`로 표시합니다. 데이터의 명시적인 TBD만 “일정 확정 대기”로 표시합니다. 누락은 “시간 확인 중”으로 구분합니다.
- 실제 엠블럼을 검증 후 `dist/assets/crests`에 저장하여 외부 이미지 연결 실패를 줄입니다. 각 엠블럼 권리는 해당 구단에 있습니다.
- 약 30분 간격 GitHub Actions 수집 → 테스트 → JSON 커밋 → Pages 배포. 혼잡 시 예약 실행/배포가 지연될 수 있습니다.
- 페이지 로드·새로고침·다시 활성화 시 캐시를 우회하여 최신 **저장 JSON**을 조회합니다. 서버 없는 GitHub Pages에서 매 방문마다 수집기를 실행하는 구조는 아닙니다. 화면에 실제 데이터 수집 시각을 표시합니다.
- 일시적인 실패에는 대체 소스, 그다음 기존 정상 데이터를 사용합니다. 전체 데이터 검증이 실패하면 배포를 중단해 마지막 정상 사이트를 보존합니다. 2시간 이상 오래된 데이터는 화면에서 알립니다.
- 공개 비공식 엔드포인트는 향후 변경될 수 있습니다. 수집 실패는 저장소 Actions 실행에서 확인하고, 각 경기의 원문 링크로 확인할 수 있습니다.

## GitHub Pages 배포

1. 저장소의 기본 브랜치를 `main`으로 설정하고 이 프로젝트를 업로드합니다.
2. Settings → Pages → Source를 **GitHub Actions**로 선택합니다.
3. Actions → **Refresh football data and deploy**를 실행합니다.
4. 성공한 실행의 `github-pages` 환경에 공개 URL이 표시됩니다.

별도 API 키나 비밀키가 필요하지 않습니다. 워크플로는 저장소 콘텐츠 갱신과 Pages 배포 권한만 사용합니다. 정적 공개 디렉터리에는 인증 정보가 포함되지 않습니다.

## 장애 검증

`DISABLE_PROVIDERS=FotMob`으로 수집하면 유럽은 ESPN, 인천은 365Scores로 복구합니다. `OUTPUT_JSON`을 지정해 테스트 출력을 별도 경로에 저장할 수 있습니다. `SKIP_LOGOS=1`은 반복 테스트에서 이미지 재수집만 생략합니다. `STRICT_DATA=1`은 요구 데이터가 불완전하면 종료 코드 1을 반환합니다.
